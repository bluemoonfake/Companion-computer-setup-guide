# 01 — Ubuntu 24.04 LTS

## 1. Install OS

Flash the correct Ubuntu 24.04 ARM64 image for Raspberry Pi 5 or the vendor Noble image for Orange Pi 6. Use a compatible BSP, reliable power and local console; flashing erases the selected drive.

- [Raspberry Pi Ubuntu image](https://ubuntu.com/download/raspberry-pi)
- Jetson: verify JetPack/L4T and Ubuntu compatibility first.

~~~bash
cat /etc/os-release
uname -a
dpkg --print-architecture
df -h /
free -h
~~~

## 2. Dependencies

Review upgrades to vendor kernel/bootloader packages before accepting.

~~~bash
sudo apt update
sudo apt upgrade
sudo apt install -y git curl ca-certificates jq build-essential cmake ninja-build pkg-config \
  python3 python3-pip python3-venv python3-setuptools python3-numpy \
  python3-serial usbutils pciutils iproute2 iputils-ping ethtool tcpdump \
  minicom psmisc openssh-server avahi-daemon avahi-utils locales network-manager
sudo locale-gen en_US.UTF-8
sudo update-locale LANG=en_US.UTF-8
~~~

Optional application libraries; use a virtual environment for pip packages.

~~~bash
sudo apt install -y python3-opencv python3-paho-mqtt
~~~

## 3. User and hostname

Create ctuav only if it does not already exist; use a unique hostname. Keep the original account until services are migrated.

~~~bash
sudo adduser ctuav
sudo usermod -aG sudo,dialout ctuav
sudo hostnamectl set-hostname orangepi
sudoedit /etc/hosts
~~~

Update the existing 127.0.1.1 hostname entry. Log in again to apply group membership.

~~~bash
id
sudo whoami
sudo systemctl enable --now ssh avahi-daemon
~~~

From a trusted LAN client (replace hostname/user if different):

~~~bash
ssh-copy-id ctuav@orangepi.local
ssh ctuav@orangepi.local
~~~

## 4. Network and time

NetworkManager must manage the intended NICs. If using networkd, back up Netplan and migrate the intended interfaces from a console; do not change a working renderer globally.

~~~bash
systemctl is-active NetworkManager
nmcli device status
ip -br address
ip -4 route
timedatectl status
~~~
